# sessions/ — 会话存档

重要会话的完整存档：讨论过程、推理链条、被否决的方案、结论怎么来的。

## 与 memory/ 的分工（重要）

`AGENTS.md` 规定 **`memory/` 是项目事实的唯一事实来源**。本目录不改变这一点。

| | `memory/` | `sessions/` |
|---|---|---|
| 内容 | **结论**：进度、决策、术语、坑 | **过程**：怎么推导出这些结论的 |
| 形式 | 结构化、一条一个要点、可检索 | 叙事、长文、含数据与论证 |
| 读者 | 新会话开始时 AI 快速接上下文 | 需要复盘"当时为什么这么决定"时 |
| 权威性 | 冲突时**以 memory/ 为准** | 背景材料，不是事实来源 |

**写入纪律**：存了会话之后，**必须把其中的结论按 `memory/README.md` 的规则
同步进 `memory/`**。只存会话不更新 memory，等于把事实藏进了长文里。
