# Schema 设计说明

每条设计决策都写清"为什么"和"当时的取舍"。
`models.py` 是 schema 的唯一事实来源，`schema/curriculum-graph.schema.json` 由其导出。

---

## D1：用年级（1-9）而非年龄作为进度基元

**为什么**：中国课标按年级组织，家长和老师的心智模型就是年级。
Marble 用 `ageRangeStart/End` 是因为英美课标跨国对齐需要一个国别无关的量。

**取舍**：牺牲了跨国可比性。适配 Marble 数据时年龄→年级映射是有损的
（`grade = age − 5`，超出 1-9 一律夹逼），所以 `adapters/marble.py` 的产出
**只能用于校验层验证，不能当数据用**。

---

## D2：加 `misconceptions` 字段（Marble 无）

**为什么**：这是诊断类应用最值钱的部分。有先修图只能回答"下一步学什么"，
有误概念才能回答"他为什么这么想"。中国有大量教研文献积累了典型错例，是现成的富矿。

**结构**：`statement`（孩子会怎么想，用孩子的口吻）+ `probe`（能诱发该错误的提问）
+ `correction_hint`（往哪儿引，不是标准答案）。

三段式而非一句话，是因为 LLM 要用它做三件不同的事：识别、验证、纠正。

**取舍**：字段变重，人工审核成本上升。默认空列表，不强制。

---

## D3：加 `revisits` 螺旋边（Marble 无）

**为什么**：中国课标是明确的螺旋结构 —— 分数在三上（初步认识）、五下（意义与性质）、
六上（分数除法）各来一轮。这**不是先修关系**（它本来就是同一个概念），
扁平 DAG 表达不了"同一概念的不同轮次"。

**取舍**：引入第二类边，图的语义变复杂，下游消费者要处理两种边。
换来的是能表达中国课标的固有特征。

**约束**：螺旋边必须指向更高年级（`REVISIT_NOT_ADVANCING` 是 ERROR），
且不参与先修边的环检测 —— 两类边的 DAG 性质是分开算的。

---

## D4：每节点独立 `provenance`（Marble 只有仓库级）

**为什么**：Marble 的 `PROVENANCE.md` 通篇讲授权和许可，
**完全没有说明生产方法，也没有任何 QA 流程描述**。
1590 节点 + 3221 条带理由的边，纯人工成本极高，大概率是 LLM 生成 + 人工抽检 ——
但没有公开校验方法就无法判断哪条可信。

**结构**：`method`（生成方式）、`review_status`（unreviewed / self_reviewed /
expert_reviewed）、`reviewer`、`reviewed_at`、`confidence`。

**取舍**：`MISSING_PROVENANCE` 定为 ERROR 而非 WARNING —— 宁可让 CI 一开始就红，
也不要养成"先攒数据、回头补来源"的习惯，那种债事后一定还不上。

---

## D5：双层对齐 —— `standards` + `textbook_units`

**为什么**：中国的教学实际由**教材**驱动而非课标驱动。
只挂课标条目，中国用户找不到入口。

**法律约束落进结构**：
- `Standard` 只有 `curriculum` + `code`，**没有存条目原文的字段** ——
  codes-only 不是靠纪律保证，是靠 schema 保证。
- `TextbookUnit` 只有版本/册次/单元号/单元名（事实性描述），
  没有存教材正文、例题、习题的地方。

依据见 `feasibility-analysis.md` 闸门 1。

---

## D6：`extra="forbid"` 全局开启

**为什么**：未知字段静默通过，是数据集腐化最常见的入口 ——
上游多写一个字段没人发现，下游按老 schema 读，问题几个月后才暴露。

**取舍**：schema 演进时所有旧数据会立刻报错。这是想要的行为。

---

## D7：语义校验用依赖注入的 judge

**为什么**：`NAME_DESC_MISMATCH` 是唯一无法用规则判定的校验
（Marble 至少 4 个已确认反例，如 `mt_GzcJEVkNRn` 名为 Understanding angles、
描述却是用边长相乘求面积）。

**取舍**：判定器做成 `Protocol`，CI 里接真 LLM，测试里接确定性假判定器。
代价是这项校验的可靠性取决于 judge 质量，且要花 API 钱。

**关键设计**：不传 judge 时**不是静默跳过**，而是产出 `CONSISTENCY_SKIPPED` 警告。
静默略过会让"CI 绿了"被读成"全都查过了" —— 这正是 Marble 让人误判其数据质量的方式。

---

## D8：`GRADE_INVERSION` 按边强度分级

**为什么**：hard 边倒挂是硬错误（真的先修关系不可能"先学后面的"）；
soft 边倒挂在真实课标里可能合理（互相支撑的概念在同一学段来回引用）。

**证据**：Marble 的 56 条年龄倒挂里 48 条是 soft、8 条是 hard ——
一刀切成 ERROR 会产生大量噪音，一刀切成 WARNING 会漏掉真问题。
